# 🍑 말랑말랑 과일 가게 🍉

귀여운 수박 합치기 브라우저 게임입니다. HTML/CSS/JavaScript만 사용해 서버나 설치가 필요하지 않습니다.

## 실행 방법

- `index.html`을 더블클릭해서 브라우저로 열면 바로 실행됩니다.
- 컴퓨터: 마우스로 위치를 정한 뒤 클릭 / 방향키 좌우 이동 후 스페이스바로 떨어뜨리기
- 휴대폰: 게임 화면에서 떨어뜨릴 위치를 터치

## GitHub Pages 배포

1. GitHub에서 새 **Public** 저장소를 만듭니다.
2. 이 폴더의 `index.html` 파일을 저장소 최상위(root)에 업로드하고 커밋합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치 **main**, 폴더 **/(root)**를 선택하고 Save를 누릅니다.
5. 배포된 `https://사용자명.github.io/저장소명/` 주소로 플레이할 수 있습니다.

## 기능

- 파스텔톤 과일 캐릭터와 표정
- 중력, 충돌, 같은 과일 합치기
- 과일 10단계 진화 및 최고 기록 (브라우저 localStorage)
- 모바일 터치 및 키보드 조작
- 효과음 켜기/끄기, 게임오버, 다시 시작

외부 라이브러리나 이미지 파일 없이 단일 HTML로 작동합니다. Google Fonts는 인터넷 연결 시 적용되며, 오프라인에서도 기본 글꼴로 정상 실행됩니다.
